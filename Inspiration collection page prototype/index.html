结合产品设计规范文档与三张视觉参考（深色 CAPTURA / 灵感星云 / 热点工具），按 H5 与移动端适配原则设计。

响应式 可交互动效 移动端适配 pure HTML/CSS/JS 无依赖 设计系统变量

设计原则（贯穿 3 套方案）

  • calm / airy / tactile / traceable / focused — 文档原关键词
  • 两主按钮等权重，不暗示主次操作
  • 类型色限制为 5 个低饱和族，并叠加图标/标签
  • 日期滚轮可独立滚动，月日联动收敛，鼠标仅影响指针所在列
  • 白板是「有限自由布局」，贴片可拖动但有秩序
  • 移动端白板 → 纵向贴片流 + 缩略地图
  • 多选第一张后底部操作栏滑入；选中态除描边还要复选标记
  • 所有主操作可由键盘完成（含类型选择器、贴片选择）
  • 遵循 prefers-reduced-motion，关闭非必要动效
方案 A · Calm

奶油白基础款

秩序感 · 阅读舒适 · 工具气质

▦ 浅色 · 纸片
CSS 变量 纸片卡 浅色网格 手工感阴影

设计取向

完整遵循文档推荐的"奶油白 + 低对比网格 + 大留白"骨架，颜色全部使用低饱和 #7867a8 / #6f91aa / #b77b83 等。适合长时间停留，注意可扫读性，参照 Notion / Are.na 风格。

差异化亮点

  • 等权重大按钮：纸片卡 + 同色高亮 icon
  • 日期滚轮三列独立滚动 + 居中吸附
  • 贴片 4–8px 旋转 + 拖动后保存坐标
  • 底部多选操作栏 slide-up 进出

适合场景

文档型 / 工具型工具主基调；用户长时间在桌面写作整理；和现有 Notion / 飞书 / 石墨文档视觉体系相近。

方案 B · Nebula

深色星云沉浸款

未来感 · 情绪化 · 灵感可视

✦ 深色 · 玻璃
星云光晕 玻璃拟态 品牌渐变 星点漂移

设计取向

完整复刻图一（CAPTURA 暗色 App）与图二（灵感星云）的氛围。深色基底 + 多色径向光晕 + 玻璃质感卡片 + 渐变品牌标识。适合强调"灵感宇宙"这一隐喻，给创作空间未来感。

差异化亮点

  • 三层视差星点漂移（20–40s 循环）
  • 玻璃卡 + 鼠标位置径向高光
  • 类型色使用霓虹色 + 发光 box-shadow
  • 白板 + 星云双视图切换（SVG 连接线）
  • 音频波形条带动画

适合场景

产品重情绪与品牌识别；以浏览灵感、激发为高频路径。适合夜间使用 / 沉浸式创作时段。注意：文档提示深色背景不适合长文编辑。

方案 C · Hybrid

混合调性

理性工作 · 沉浸创作

◐ 浅 + 深 · 可切换
分层调色 无缝过渡 明/暗双主题 模式引导

设计取向

首页与记录页走浅色系（不易疲劳），灵感库白板走深色（沉浸感）。两套色板通过 CSS 变量集中管理，切换有 0.5s 过渡。用户保留选择权（localStorage），且永远不强制。

差异化亮点

  • 首页右侧"开始创作"按钮悬停时露出深色预览带，提示即将进入沉浸模式
  • 顶部有明/暗 ☀ / ☾ 切换器，0.5s 平滑过渡
  • 记录页编辑器模拟"纸页"（左侧 1px 红线）
  • 类型色用环形细描边色块，不喧宾夺主
  • AI 建议用"批注"左边框条

适合场景

用户昼夜 / 不同时段使用偏好差异大；产品希望兼顾理性工具感与创作沉浸感；同时保留用户选择权。工程实现复杂度略高，但体验最佳。

设计与开发说明

视觉差异化要点

· 遵循文档给出的色彩规范，所有色彩使用 CSS 变量，未来可一键切换主题
· 仅在浮动面板使用玻璃拟态，正文保持高对比度（WCAG AA）
· 类型色限制为 5 色低饱和族群（紫 / 蓝 / 玫瑰 / 苔藓 / 琥珀），最多加"问题"红
· 贴片永远带类型文字标签，不单独靠颜色传达信息（色盲友好）

交互动效要点

· 页面主转场 180–260ms，使用 cubic-bezier(.2,.7,.3,1)
· 星点漂移 20–40s 循环，位移不超过 12px（方案 B）
· 贴片进入：淡入 + 4–8px 位移，禁用持续旋转
· 多选操作栏 transform 滑入 + 0.3s 过渡
· 主题切换使用 0.5s 同步过渡（方案 C）

移动端适配策略

· viewport meta + safe-area-inset-bottom（已启用）
· < 720px：白板的绝对定位贴片改为静态贴片流 + 缩略地图
· 操作栏全屏宽度 + 左对齐
· 大按钮在 < 960px 时变单列堆叠
· 拍照 / 录音按钮置灰，hover 提示"移动端后续支持"
· 字体 16px 起步，避免 iOS 缩放

技术约束

· 纯 HTML + 内联 CSS + 少量原生 JS，零依赖、可离线打开
· system font stack，无网络字体请求
· 所有图片使用 SVG data URI 占位（草图 / 音频 / OCR 三态）
· 主题状态用 localStorage 持久化（方案 C）
· 严格遵循 prefers-reduced-motion，所有动画可降级
· 键盘可达：Tab / Space / Enter / Esc 全部可完成主操作

下一步可演进

· 进入：基于选定方案输出高保真设计稿（Figma）
· 进入：用 React / Vue 实现真实组件，CSS 变量复用
· 进入：补全移动端 PWA + 拍照录像 API 接入
· 进入：AI 分类、OCR、ASR 接入；类型色与 AI 标签融合
· 进入：白板引入网格层、坐标存储、缩略地图视图
