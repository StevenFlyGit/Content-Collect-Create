# Nebula Edition (方案 B) · 切图清单

> **高保真设计稿**：`index.html`（本目录根）— 在浏览器中打开即等于 Figma 文件概览。
> **资源类型**：SVG 矢量源 + PNG 位图（@1x / @2x / @3x）
> **设计基准**：24px viewBox · 描边 1.6 · 默认描边色 `#e9e6ff`
> **生成方式**：`build_assets.py`（单一声明式 spec → SVG + PNG 严格同步）

---

## 1. 目录结构

```
Figma-highfidelity-slices/
├── index.html                     ← 高保真设计稿（Figma 等效）
├── 切图清单.md                    ← 本文件
├── build_assets.py                ← 资产生成脚本
└── assets/
    ├── svg/                       ← 矢量源（前端首选）
    │   ├── common/                6 个
    │   ├── nav/                   5 个
    │   ├── capture/               4 个 + type-swatches.svg
    │   └── timeline/              5 个
    └── png/                       ← 位图（@1x / @2x / @3x）

        ├── @2x/  (48px)           21 个
        └── @3x/  (72px)           21 个
```

总计：**21 个 SVG** + **63 个 PNG**（21 × 3 分辨率）

## 2. 命名规范

| 格式 | 路径模式 | 说明 |
|---|---|---|
| 矢量 | `assets/svg/<group>/<name>.svg` | group ∈ {common, nav, capture, timeline} |
| 位图 | `assets/png/@<Nx>/<group>__<name>.png` | group 与 name 用双下划线分隔（与 SVG 单斜杠区分） |
| 分辨率 | `@1x = 24px` · `@2x = 48px` · `@3x = 72px` | icon 设计基准 24px；不同 DPI 直接换 Nx |

## 5. 组件状态 → 资源策略

| 状态 | 推荐实现方式 |
|---|---|
| **default** | 直接使用 SVG（`<img src="...svg">` 或 inline）|
| **hover** | SVG + CSS `color`/`stroke` 变化；PNG 不可改色，需另出 hover 版 |
| **active** | 同上；或包一层带选中光晕的容器 |
| **disabled** | 不用切图；用 CSS `opacity: .42` 即可 |

> 所有 PNG 都是单一色（描边色 `#e9e6ff`，填充按需），hover/disabled 状态用 CSS 控制。

## 6. 前端使用建议

```html
<!-- 优先 SVG（可改色、可缩放、体积小） -->
<img src="assets/svg/capture/record.svg" alt="录音" width="18" height="18">

<!-- 离线 / 跨域场景用 PNG @2x（视觉最清晰） -->
<img src="assets/png/@2x/capture__record.png" alt="录音" width="24" height="24">

<!-- 直接 inline（可改 stroke="currentColor"） -->
<svg viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="1.6">
  <rect x="9" y="3" width="6" height="11" rx="3"/>
  ...
</svg>
```

**TypeScript / React 用法**：把 SVG 文件直接 import 或用 `?react` 加载器转成组件。属性可改 `color` / `size`。

**PWA / sprite**：若需将多图标合并为 sprite，参考 `assets/svg/capture/type-swatches.svg` 的结构（`<svg viewBox>` 内放多 `<g>`）。

## 8. 注意事项

1. **PNG 透明背景**：可叠加在任意深色容器上；若需浅色场景，需重新着色或出反向版本。
2. **SVG 默认描边色** `#e9e6ff`：前端若想跟随父级文字色，把 `stroke="#e9e6ff"` 改为 `stroke="currentColor"`。
3. **超采样质量**：PNG 渲染时已 12× 超采样再 LANCZOS 下采样，`@2x` 是视觉甜点；`@3x` 仅为 4K 屏准备。
4. **色盲友好**：六色 + 文字 pill 标签双重编码，符合 WCAG 色盲可达性。
5. **资源与设计稿 1:1 对应**：`index.html` 中的图标展示位即对应本清单的 SVG/PNG 文件；修改任一文件后刷新页面即可看到。
