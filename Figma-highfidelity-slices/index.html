01 总览

本方案的设计哲学与版式基础

设计原则

沉浸感
深色星云作底，让灵感有"被包裹"的归属感，避免白底工作台的冷感。
自由有序
白板贴片允许位置自由，但类型色与 AI 标签提供统一锚点。
类型优先
六色低饱和色板：想法 / 引用 / 随感 / 待办 / 案例 / 问题，色盲友好。

06 前端交付说明

CSS 变量、文件命名、组件映射、注意事项

CSS 变量（直接复用）

:root {
  /* 宇宙背景 */
  --cosmos-deep: #07060f;
  --cosmos:     #0e0c1d;
  --cosmos-2:   #16142a;

  /* 表面（玻璃拟态） */
  --surface:        rgba(255, 255, 255, 0.04);
  --surface-strong: rgba(255, 255, 255, 0.09);
  --line:           rgba(255, 255, 255, 0.10);

  /* 文字 */
  --ink:       #f5f3ed;
  --ink-soft:  #d8d4c8;
  --ink-muted: #8d8879;

  /* 星云主色 = 类型色 */
  --nebula-violet: #a78bfa;  /* 想法 */
  --nebula-blue:   #7dd3fc;  /* 引用 */
  --nebula-rose:   #f9a8d4;  /* 随感 */
  --nebula-mint:   #86efac;  /* 待办 */
  --nebula-amber:  #fcd34d;  /* 案例 */
  --danger:        #fca5a5;  /* 问题 */

  /* 圆角 / 阴影 / 缓动 */
  --radius-panel: 20px;
  --radius-card:  14px;
  --radius-pill:  999px;
  --shadow-soft: 0 1px 2px rgba(0,0,0,.3), 0 12px 32px -12px rgba(0,0,0,.5);
  --shadow-lift: 0 2px 4px rgba(0,0,0,.4), 0 24px 48px -16px rgba(0,0,0,.6);
  --ease:        cubic-bezier(.2,.7,.3,1);
}

资源命名规范

类型 路径 示例
SVG 矢量 assets/svg/<group>/<name>.svg assets/svg/capture/record.svg
PNG 位图 assets/png/@<Nx>/<group>__<name>.png assets/png/@2x/capture__record.png
分辨率 @1x = 24px / @2x = 48px / @3x = 72px icon 设计基准 24px，描边 1.6

前端推荐：图标优先用 SVG（矢量、清晰、可改色）；仅在 PWA / 跨域 / sprite 不可用时使用 PNG。

注意事项

  • 所有 SVG 默认描边色为 #e9e6ff（深紫白）；前端可改用 stroke="currentColor" 跟随父级 color。
  • PNG 透明背景，可叠加在任何深色容器上；如需浅色背景，需重新着色或反向版本。
  • PNG 已 12× 超采样 + LANCZOS 下采样，@2x 视觉质量最佳；@1x 用于性能敏感场景，@3x 用于 4K 屏。
  • 类型色板前端优先用 CSS 变量（var(--nebula-violet) 等），PNG 仅作设计参考与离线场景。
  • 本环境无法直接产出 .fig 文件；本 HTML 文档即"Figma 等效"，可用浏览器打开核对所有页面 / 组件 / 资产。
