## 0. 这份原型覆盖什么

按你的要求，本批次**只设计「灵感收集与查阅」这条链路**的界面原型与交互方案，不含选题、创作、双平台排版、发布等后续环节。

具体覆盖三条核心页面流：

| 页面 | 用途 | 对应你的需求 |
|---|---|---|
| `home` 首页 | 极简有美感的入口，双 CTA（记录灵感 / 开始创作）+ 近期灵感板 + 主理人洞察 | 「图一图二结合的感觉」「自由但不混乱」「每个页面清晰明了」 |
| `capture` 记录 | 文字 / 语音 / 图片 / 组合四种记录方式 + 可选的「灵感类型」属性 + 上传区 | 「记录可以是文字、语音、图片或组合」「先加入灵感类型属性供后续扩展」 |
| `timeline` 查阅 | 年 / 月 / 日三级滚轮选到**单一具体日期** → 该日期专属灵感白板（每灵感一张贴片）→ 多选灵感进行创作 | 「按日期滚动选择到具体的一天」「每个单一日期有单独白板」「选一个或多个灵感创作」 |

## 2. 共享的交互骨架（三套方案一致）

无论选哪套，底层交互骨架相同，保证体验连贯：

1. **双 CTA 首页（Hero）**：`记录灵感` → `capture`；`开始创作` → `timeline`。
2. **状态条 / 近期灵感板**：首页展示累计灵感数、最近记录等轻量状态，降低空页面焦虑。
3. **「主理人洞察」尾行**：首页底部放一条柔和的产品理念文案（你定义的「热点 / 灵感」产品哲学占位）。
4. **记录模式切换**：`文字 / 语音 / 图片 / 组合` 四个 Tab；编辑器带自动保存态；语音模式有实时波形动效；上传区支持图片 / 音频 / 链接 / 剪贴板。
5. **可选的灵感类型**：`capture` 页提供 6 个类型标签（如 文字随笔 / 截图素材 / 语音速记 / 链接收藏 / 图片灵感 / 其他），**默认不强制**，仅为后续「按类型分类」扩展预留属性位。
6. **日期三级滚轮**：`timeline` 用 年 / 月 / 日 三个独立滚轮，支持拖拽 / 滚轮 / 点击 / 触摸；滚轮始终收敛到**单一具体日期**。
7. **日期专属白板**：选定日期后展示该日白板，每条灵感是一张可旋转贴片（绝对定位 + 随机轻微旋转），模拟「灵感随手贴」的自由感但不混乱（区域有边界）。
8. **多选进入创作**：白板贴片支持勾选（多选高亮 + 角标计数），底部浮现「开始创作（N）」悬浮按钮。
9. **移动端适配**：`960px` 与 `640px` 两个断点；桌面端侧栏 / 浮窗在移动端收为底部胶囊栏（bottom pill bar），滚轮竖向堆叠。

## 3. 各方案设计令牌（Design Tokens）

### A · 纸感手作 `scheme-A-papercraft`
- 画布：`#FAF6EE` 暖白 / `#F3EBD8` 纸纹二层
- 墨色：`#1F1B17` 主墨 / `#4F4A41` 次墨 / `#807868` 弱墨
- 强调：`#B95727` 暖橙（记录 CTA）/ `#2D3E5F` 深蓝（创作 CTA）
- 字体：标题 `Noto Serif SC`（衬线）；正文系统无衬线；等宽 `JetBrains Mono`
- 卡片：便签纸卡片（黄 / 玫 / 薄荷 / 蓝 / 丁香 / 桃 / 陶），轻微 `rotate` 错位
- 质感：SVG 纸纹噪点 + 柔和投影；圆角 18px

### B · 极光夜行 `scheme-B-aurora`
- 背景：`#0E0B1F` 深空 / `#16122B` 卡片底
- 辉光：紫 `#8B5CF6` → 青 `#34D399` → 粉 `#F472B6` 渐变流光
- 文本：白 `#F5F3FF` / 弱 `#A9A3C9`
- 字体：全站 `Inter` + 系统无衬线；标题渐变文字
- 卡片：玻璃拟态（`backdrop-filter` 模糊 + 半透明描边），`::before` 顶部光条
- 动效：星点漂移 `.stars` + 极光团 `.aurora` 缓慢位移；脉冲圆点

### C · 中和编辑 `scheme-C-harmonic`
- 背景：`#F1EEE8` 暖灰 / `#E7E2D8` 二层
- 强调：`#B68764` 陶土 / `#586E51` 苔绿（双 CTA 区分）
- 文本：`#23201B` 主 / `#6B655B` 次
- 字体：衬线 `Noto Serif SC` ＋ 等宽 `JetBrains Mono` 混排（编辑 / 杂志感）
- 卡片：masonry 错落便签；月份用 `JAN–DEC` 缩写（等宽）映射数字
- 气质：克制、留白多、强调「桌面 / 一张桌子」的隐喻

## 5. 如何预览

纯静态 HTML，无需构建。两种方式：

**方式一 · 直接打开**
双击任意 `*.html` 文件用浏览器打开即可（交互、动效、移动端断点均生效）。

**方式二 · 本地静态服务器（推荐，移动端调试更准）**
```bash
# 在 prototype2 目录下
cd "Content-Collect-Create/Inspiration collection page prototype2"
python -m http.server 8090 --bind 127.0.0.1
# 浏览器访问：
#   http://127.0.0.1:8090/index.html        （总览）
#   http://127.0.0.1:8090/scheme-A-papercraft/home.html
```
用浏览器开发者工具的「设备工具栏」切换手机视口（如 iPhone 390×844）即可验证移动端适配。
